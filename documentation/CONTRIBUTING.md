# Contributing to Job Hunt Helper

## Development Workflow
1. **Branching**: Always create a feature branch before making changes.
2. **Testing**: Run tests (`pytest`) and ensure coverage is > 70% before submitting a PR.
3. **Linting**: Keep code clean, use type hinting for all new Python functions.

## Project Structure
- Code belongs in `app/`.
- Templates belong in `app/templates/`.
- All CSS/JS should go into `app/static/`.

## Running Tests
Use pytest:
```bash
python -m pytest
```
